# FormulaDash 🏎️

Check it out here: [FormulaDash](https://www.formuladash.com/)

A full-stack Formula 1 dashboard application providing race results, results from all other sessions, driver standings and constructor standings.

## Features
- **Race Weekend Schedule:** Detailed schedule of upcoming sessions
- **Driver Standings:** Session-long standings displayed in a graph and current standings in a table
- **Last Session Results:** In-depth results table of the most recent session
- **Team Standings**: Constructor standings displayed in a table

## Tech Stack
**Frontend**
- Next.js
- React
- TypeScript
- Tailwind CSS
- Recharts

**Backend**
- Next.js
- Supabase
- OpenF1 API
